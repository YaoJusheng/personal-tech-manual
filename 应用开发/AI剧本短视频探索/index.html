    一、需求目标¶

    1.1 目标定义¶

    利用 AI 工具实现从小说/剧本创作 → 分镜设计 → 角色视觉设定 → 视频生成 → 配音配乐 → 剪辑发布的全流程自动化，以最低成本、最短时间产出可发布的短视频/短剧内容。

    1.2 核心需求¶

    需求 说明
    低成本 单集算力成本控制在 50-200 元以内，个人/小团队可承担
    省时省力 单集制作时间 1-3 小时（极速流）或 3-5 天（精品流）
    角色一致 同一角色在不同场景/镜头中保持面部、服饰一致
    音画同步 配音与口型、情绪匹配，BGM 与画面节奏吻合
    可商用 生成内容的版权/商用授权清晰，避免侵权风险

    1.3 产出形态¶

    • 短视频（1-3 分钟）：资讯吐槽、热点追风、知识科普
    • AI 漫剧/动态漫（3-5 分钟/集）：二次元风格连载短剧
    • AI 仿真人短剧（1-3 分钟/集）：接近真人画面的短剧

    二、评估方案¶

    2.1 全流程五步拆解¶

    第一步：剧本创作 ─→ 第二步：分镜设计 ─→ 第三步：视觉/视频生成 ─→ 第四步：配音配乐 ─→ 第五步：剪辑发布
   (LLM)           (AI分镜工具)        (图生图/图生视频)          (TTS+BGM)         (剪辑软件)

    2.2 各环节工具选型¶

    第一步：剧本创作¶

    专业小说/剧本创作工具（支持连贯性与文本管理）¶

    通用 LLM（如 DeepSeek、Claude）只能"对话式"写作，写到几十万字后角色性格突变、时间线矛盾频出。以下专业工具专门解决长篇连贯性、角色管理、世界观维护等核心痛点：

    工具 核心能力 连贯性方案 费用 适合
    马良写作 7 个 AI Agent 协作（设定/蓝图/生成/一致性/纠错/结构/主管），知识图谱引擎，三级大纲体系 一致性 Agent 实时检查剧情与设定冲突，防止"吃书"；知识图谱自动提取角色/地点/事件关系 注册送 500 积分，按量付费 中文网文长篇创作首选
    NovelForge 卡片式创作 + 知识图谱（Neo4j）+ 上下文注入 @DSL + 工作流系统 写作时自动注入角色卡/场景卡/组织卡信息；关系图谱追踪角色关系；动态信息记录实体状态变化 免费（开源） 有技术能力的长篇小说作者
    落笔AI写作 可视化卡片/节点编辑，设定与正文深度关联，多模型切换 结构化数据联动，写作时自动调用角色和背景设定，避免前后矛盾 付费 网文日更、可视化创作
    创一AI 专为短剧行业打造，剧本→拆片全流程 短剧剧本格式规范，角色设定管理 付费 短剧专业剧本
    FeelFish PC 客户端，专为小说创作者设计 本地化管理，角色/场景一致性追踪 付费 桌面端小说创作
    唐库 一键生成 1-500 万字长篇，大纲→章纲→正文全自动化 聚合智慧工作流，但连贯性一般，需人工审核 付费 超长篇网文量产

    连贯性对比：

    痛点 通用 LLM 马良写作 NovelForge
    角色性格突变 无法防止 一致性 Agent 检查 角色卡注入上下文
    地名/人名混淆 经常出错 知识图谱自动关联 卡片引用 @DSL
    时间线矛盾 无法检测 设定 Agent + 一致性 Agent 分卷/阶段/章节层级约束
    世界观设定冲突 无法管理 世界观设定管理（版本追溯） 世界观卡 + 组织卡联动
    伏笔遗忘 常见问题 故事画布可视化伏笔 上下文自动注入相关卡片

    AI 漫剧剧本特殊性：

    • AI 短剧剧本需要详细场景描写（真人剧不需要形容词，AI 需要视觉描述来生成画面）
    • 建议每集 800-1500 字，包含场景描述、角色动作、对白和情绪标记
    • 剧本应标注镜头语言提示（特写、中景、远景），便于后续分镜环节使用

    剧本提示词模板：

    你是一位专业的短剧编剧。请根据以下要求创作一集短剧剧本：

【题材】都市言情
【集数】第1集（共20集）
【时长】约2分钟
【风格】甜宠+反转
【核心角色】
- 林晓：25岁，职场新人，性格倔强
- 陆川：28岁，集团总裁，外冷内热

【要求】
1. 开头3秒要有强钩子
2. 每15-20秒一个情绪转折
3. 结尾留悬念
4. 场景描写要详细（包括环境、光线、角色位置），便于AI视频生成
5. 每个角色对白标注情绪：[愤怒]、[温柔]、[惊讶]等
6. 输出格式：场景号 + 场景描述 + 角色动作 + 对白（标注情绪）

    常用 AI 指令参考：

    任务 指令示例
    撰写大纲 "请帮我构思一个主角是外卖骑手的都市悬疑短剧大纲，共5集，每集2分钟"
    构思人设 "请为主角生成详细的人物小传，包括外貌、性格、背景故事和口头禅"
    对白润色 "请将这场争吵戏对白改得更尖锐、更具冲突性"
    爆款分析 "请分析近期抖音播放量最高的3部短剧的剧情结构和爽点设计"
    视觉描述 "请将以下对白转化为详细的分镜描述，包含镜头景别、光线、角色位置"

    第二步：分镜设计¶

    专业 AI 分镜工具¶
    工具 核心能力 角色一致性 剧本→视频 费用 适合
    Drawstory 专业导演模式，内置电影镜头语言逻辑 上传角色参考图和场景资产，多分镜格中保持一致 不支持 ~$19-26/月 快速分镜草稿、传统视觉风格
    Katalist.ai 4-5 分钟完成剧本→分镜，支持 10 个自定义角色 角色跨场景一致，Lip-Sync，Premiere Pro 导出 支持 $39/月 角色一致性要求高的项目
    LTX Studio 深度创意控制，光影/动态/Pitch Deck 整合 有限 分镜与视频独立工作流 $15/月起 专业前期制作规划
    Boords 协作审批流程：评论/版本/分享/审批 无 不支持 $44/月 团队协作、客户审批
    即梦AI 画布 对话式 Agent 辅助排版分镜格 Seedance 角色档案 支持 免费层/付费 中文创作者首选
    DomoAI Frames-to-Video，2-8 帧分镜转动态预览 Advanced Model 多风格一致 支持 免费层/付费 动态分镜验证
    手动分镜 用 PPT/Keynote 手动排列图片 无 不支持 免费 零成本方案

    分镜工具选择建议：

    • 需要角色一致性 + 剧本到视频：Katalist.ai（最完整的分镜→视频流水线）
    • 需要团队协作审批：Boords（评论/版本/分享/审批流程最完善）
    • 中文创作者快速入门：即梦AI 画布（一站式 + 分发闭环）
    • 零成本方案：手动 PPT 排列图片

    分镜设计要点：

    • 每集 8-15 个分镜格，每格对应一个镜头
    • 极速流可跳过完整分镜，只生成 5-8 个关键帧画面
    • 精品流应在分镜环节投入 70% 的精力，这是决定成片质量的关键

    三、实际落地¶

    3.1 方案 A：极速流（1 小时出片，单集 <50 元）¶

    适用：资讯吐槽、热点追风、短视频日更、矩阵号运营

    步骤1：剧本生成（10 分钟）
  └─ 用 DeepSeek 抓取今日热搜 + 生成吐槽文案
  └─ 要求：黄金3秒开场 + 每15秒一个反转 + 结尾互动钩子

步骤2：关键画面生成（15 分钟）
  └─ 用 DALL·E 4 或 Midjourney 生成 5-8 个核心场景画面
  └─ DALL·E 4 文字渲染能力强（适合弹幕、截图类内容）

步骤3：动态化处理（10 分钟）
  └─ 导入可灵AI/Runway，用"首尾帧控制"生成过渡动画
  └─ 简单镜头推拉 + 微表情变化即可

步骤4：配音配乐（10 分钟）
  └─ 剪映 AI 配音 + 自动踩点卡点
  └─ 或 MiniMax TTS + Suno BGM

步骤5：剪辑导出（15 分钟）
  └─ 剪映一键导出，同时发布抖音/快手/视频号/小红书

    成本估算：

    项目 费用
    剧本（DeepSeek） 免费
    图片生成（Midjourney/DALL·E） 约 5-10 元
    视频生成（可灵/Runway） 约 10-20 元
    配音（MiniMax/TTSMaker） 免费
    BGM（Suno 免费层） 免费
    合计 15-30 元/集

    3.2 方案 B：精品漫剧流（3-5 天/集，单集 500-2000 元）¶

    适用：剧情类漫剧、连载 IP、品牌定制、出海漫剧

    阶段1：资产库建设（3-5 天前置，一次性投入）
  ├─ 角色资产：Stable Diffusion + LoRA 微调（30-50 张图训练）
  ├─ 场景资产：Midjourney V7 批量生成核心场景"母版图"
  └─ 道具资产：即梦AI 图生图，多角度素材库

阶段2：分镜设计（每集 1-2 天，投入 70% 精力）
  ├─ Drawstory 专业导演模式，导入剧本自动拆解镜头
  ├─ 上传角色 LoRA + 场景资产，确保分镜与最终视频对齐
  └─ DomoAI 生成动态分镜预览，验证节奏和音画配合

阶段3：视频生成（每集 1 天）
  ├─ Midjourney V7 --cref --cw 80 批量生成镜头底图
  ├─ Seedance 2.0：上传参考视频控制动作（武打/舞蹈）
  ├─ 可灵 3.0：处理复杂人体动作（肢体变形少）
  └─ SkyReels-V4：最终合成（毫秒级口型对齐）

阶段4：音频后期（每集 0.5-1 天）
  ├─ ElevenLabs v3 / Fish Audio：为每角色建立独立声线档案
  ├─ 剧本标注情绪标记：[愤怒]...[温柔]...[低落]...
  ├─ Suno v4 定制专属 BGM
  └─ 剪映/Premiere Pro：拟声字特效 + 环境音

阶段5：分发运营（持续）
  ├─ 即梦AI 分发闭环：一键分发抖音/快手/红果/番茄
  ├─ 不同标题和封面 A/B 测试
  └─ 数据反馈回剧本环节，动态调整后续剧情

    视频生成（可灵/即梦） 约 200-400 元/集

    📝 注意事项与避坑指南¶

    • 注意免费额度限制：各工具的免费额度各有不同，如TTSMaker每周约3万字，制作前做好规划。
    • 输出格式：输出前注意检查分辨率等设置。个人视频一般选择1080p即可，无需盲目追求4K。
    • 视频平台要求：国内主流短视频平台如抖音、快手等，对竖屏（9:16）视频的播放支持更好。
    • 商用版权风险：各平台对免费生成内容的商用授权规定不同，请务必在项目前期仔细阅读相关条款。例如TTSMaker明确生成内容可商用，但其他平台或具体音色可能需要另行确认。
    • 应对视频"漂移"：如果发现生成的视频中人物不稳定，可尝试：
    • 使用即梦AI Seedance 2.0的多镜头叙事功能（自动维护角色档案）
    • 使用可灵 3.0（人体动力学最优，肢体变形少）
    • 使用 Stable Diffusion + LoRA（一致性接近 100%）
    • 使用 Midjourney V7 --cref --cw参数锁定角色
    • 提示词是核心壁垒：不要盲目追工具，真正拉开差距的是对每个模型上限/下限的理解和提示词结构的积累
    • 剧本优先于技术：AI 降低了制作门槛，但没有降低叙事门槛。好的故事和角色塑造才是用户最终付费的理由
    • 敏捷迭代：先做 2-3 集上线测试，根据数据反馈再决定是否加大投入，避免一次性投入大量资源

    核心结论¶

    1. 零成本可以入门：用 DeepSeek + NovelForge（开源，知识图谱保证连贯性）+ 千问APP 万相 2.6 + 即梦AI 免费层 + Edge TTS + 剪映，无需本地 GPU 即可跑通全流程
    2. 付费工具性价比高：Midjourney $10/月 + 可灵/即梦付费层，每月 100-300 元即可达到商业级品质
    3. 角色一致性是最大难点：投入 70% 精力在分镜和视觉设定环节，这是区分专业和业余的关键
    4. 工具不是壁垒，故事才是：当所有人都在用同样的 AI 工具时，真正决定作品质量的是创意和叙事能力
