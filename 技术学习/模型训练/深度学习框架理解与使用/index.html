    一、深度学习框架概述¶

    1.1 什么是深度学习框架¶

    深度学习框架（Deep Learning Framework）是用于构建、训练和部署神经网络的一系列软件工具和库的集合。它为开发者提供了自动微分、GPU 加速计算、模块化网络组件等核心能力，让开发者能够专注于模型架构设计和训练策略，而不必从零实现矩阵运算和梯度计算。

    框架解决的核心问题：

    问题 手工实现 框架提供
    梯度计算 手动推导链式法则，逐层实现 \(\partial \mathcal{L}/\partial W\) 自动微分（Autograd），自动构建计算图并求导
    GPU 加速 手写 CUDA 内核管理数据搬运和并行计算 一行 .to('cuda') 自动调度 GPU 计算
    网络层实现 每次重写矩阵乘、卷积、激活函数 预置 nn.Linear、nn.Conv2d、nn.ReLU 等模块
    优化器 手动实现 SGD/Adam 更新公式 optim.AdamW(params, lr=1e-4) 一行配置
    数据加载 手动实现批处理、打乱、多进程加载 DataLoader(dataset, batch_size=64, shuffle=True)

    1.2 从手动求导到自动微分¶

    深度学习的发展历程也是梯度计算方式的演进史：

    2010年前：手动推导梯度 → 每改一次网络结构都要重新算偏导数
   │
2012年：Theano → 符号微分（静态图，编译后再执行）
   │
2014年：Caffe → 分层注册前向/反向实现（每层手动写 backward）
   │
2015年：TensorFlow 1.x → 静态计算图（Define-and-Run）
   │
2016年：PyTorch 0.1 → 动态计算图（Define-by-Run），自动微分成为主流
   │
2017年：PyTorch 1.0 → 更成熟的 autograd + 生产部署能力
   │
2019年：JAX → 函数式自动微分 + XLA 编译优化
   │
2022年：PyTorch 2.0 → torch.compile 图模式编译加速

    1.3 框架核心能力¶

    能力 说明 重要性
    自动微分（Automatic Differentiation） 自动构建计算图并计算梯度，无需手动推导 ★★★★★ 必备
    GPU 加速 透明地将张量操作调度到 GPU 执行 ★★★★★ 必备
    模块化网络组件 预置卷积、循环、注意力、归一化等层 ★★★★☆ 高效
    优化器集合 SGD、Adam、AdamW 等优化算法实现 ★★★★☆ 高效
    数据加载 Pipeline 批处理、打乱、预读取、多线程并行 ★★★★☆ 高效
    分布式训练 数据并行、模型并行、混合精度训练 ★★★☆☆ 扩展
    模型序列化 保存/加载模型权重和检查点 ★★★★☆ 必备
    部署工具链 模型导出、量化、服务化部署 ★★★☆☆ 生产

    2.2 各框架详述¶

    PyTorch¶

    PyTorch 由 Meta AI 研发并于 2016 年开源，是目前最主流的深度学习框架。其核心设计哲学是 "Define-by-Run"——计算图在每次前向传播时动态构建，使得调试、条件分支和循环结构天然支持，Python 程序员几乎零学习成本。torch.compile（PyTorch 2.0+）通过 JIT 编译将动态图局部转为静态图，兼顾灵活性与性能。生态方面，HuggingFace Transformers、LLaMA-Factory、DeepSpeed 等主流工具均以 PyTorch 为底层，使其成为 LLM 训练的事实标准。

    TensorFlow / Keras¶

    TensorFlow 由 Google Brain 团队开发，1.x 时代以静态计算图（Define-and-Run）著称。TensorFlow 2.x（2019）将 Keras 作为官方高级 API，默认启用 Eager Execution（动态图），通过 tf.function 装饰器将 Python 函数编译为静态图以获得性能优势。TensorFlow 的最大优势在于生产部署生态：TensorFlow Serving（模型服务）、TensorFlow Lite（移动端/嵌入式）、TensorFlow.js（浏览器端）、TPU 原生支持。适合需要端到端工业级部署的场景。

    JAX¶

    JAX 是 Google Research 推出的函数式深度学习框架，其核心理念是"用纯函数做计算"。JAX 不是传统意义上的神经网络框架，而是一个可微分编程库：它将 NumPy 操作透明地映射到加速器（GPU/TPU），并通过函数变换（jit、grad、vmap、pmap）实现编译优化、自动求导、向量化和并行化。JAX 本身没有神经网络层和优化器——这些由 flax、haiku、optax 等生态库提供。JAX 在 TPU 训练、强化学习、科学计算和需要高度自定义训练循环的研究中表现出色。

    PaddlePaddle（飞桨）¶

    PaddlePaddle 是百度于 2016 年开源的深度学习框架，中文生态最为完善。其设计特色包括：动态图与静态图可自由切换、内置 Fleet API 实现分布式训练、提供丰富的预训练模型库（PaddleNLP、PaddleCV、PaddleOCR 等）。PaddlePaddle 在中文 NLP 任务（如 ERNIE 系列模型）和产业落地（工业视觉、OCR、推荐系统）中应用广泛。对于有国产化需求或需要中文技术支持的团队，PaddlePaddle 是首选。

    MindSpore（昇思）¶

    MindSpore 是华为于 2020 年开源的 AI 框架，与华为昇腾（Ascend）AI 处理器深度绑定。其核心设计为 AI 编译器架构——用户定义模型后，MindSpore 自动分析计算图并进行算子融合、内存优化等编译优化。MindSpore 支持全场景统一（端-边-云），在华为昇腾硬件生态中性能最优。对于有国产化部署需求的团队（尤其是使用华为硬件的场景），MindSpore 是重要选择。

    MXNet¶

    MXNet 由分布式机器学习社区（DMLC）创建，后被 Amazon 选为 AWS 的默认深度学习框架。它支持命令式（动态图）和声明式（静态图）编程的混合模式。随着 PyTorch 的崛起和 Amazon 逐渐转向 PyTorch，MXNet 已进入维护模式，新项目不建议采用。

    3.2 自动求导（Autograd）¶

    Autograd 是 PyTorch 自动微分引擎，它记录了张量上的所有操作，构建计算图（Computational Graph），然后通过链式法则自动计算梯度。

    3.2.1 计算图与 requires_grad¶

    # 创建需要梯度的张量
x = torch.tensor([2.0], requires_grad=True)
print(x.requires_grad)  # True

# 执行前向计算
y = x ** 2 + 2 * x + 1    # y = x² + 2x + 1

# y 有一个 grad_fn 属性，记录它是如何计算出来的
print(y.grad_fn)          # <AddBackward0 object>
# 计算图结构：
#   x → PowBackward → AddBackward → y
#   x → MulBackward → AddBackward ↗

    3.2.2 自动求导数值示例¶

    以 y = x² + 2x + 1 为例，求 dy/dx 在 x=2 处的值：

    x = torch.tensor([2.0], requires_grad=True)
y = x ** 2 + 2 * x + 1

# 手动验证：
#   dy/dx = 2x + 2
#   当 x=2 时，dy/dx = 2×2 + 2 = 6

y.backward()                    # 反向传播计算梯度
print(x.grad)                   # tensor([6.0]) ✓

# 验证数值：
# y(2) = 4 + 4 + 1 = 9
# y(2.001) = 4.004001 + 4.002 + 1 = 9.006001
# (y(2.001) - y(2)) / 0.001 ≈ (9.006001 - 9) / 0.001 = 6.001 ≈ 6 ✓

    计算图的梯度传播过程：

                        ∂y/∂x = 2x + 2 = 6
                           ↑
           ┌───────────────┴───────────────┐
           │             + (Add)            │
           │    ∂y/∂pow = 1  ∂y/∂mul = 1   │
           └───────┬───────────────┬────────┘
                   │               │
           PowBackward        MulBackward
           ∂pow/∂x = 2x=4   ∂mul/∂x = 2
                   │               │
                   └───────┬───────┘
                           │
                           x (requires_grad=True)

    3.2.3 梯度累积与 .zero_grad()¶

    每个张量的 .grad 属性默认会累积梯度（累加而非替换），因此每个 Step 前需要手动清零：

    x = torch.tensor([2.0], requires_grad=True)

# Step 1
y1 = x ** 2
y1.backward()
print(x.grad)  # tensor([4.0])  ← dy1/dx = 2x = 4

# 没有清零！继续反向传播
y2 = 3 * x
y2.backward()
print(x.grad)  # tensor([7.0])  ← 4 + 3 = 7（累加了！）

# 正确的做法：每个 Step 前清零
x.grad.zero_()
y3 = x ** 3
y3.backward()
print(x.grad)  # tensor([12.0])  ← dy3/dx = 3x² = 12（单独正确值）

    3.2.4 torch.no_grad() 推理模式¶

    推理和评估时不需要计算梯度，用 torch.no_grad() 包围可以大幅减少内存和计算：

    model.eval()  # 切换到评估模式（影响 Dropout、BatchNorm 等）
with torch.no_grad():
    predictions = model(test_data)
    # 此范围内所有计算都不会构建计算图

# 或者用装饰器
@torch.no_grad()
def evaluate(model, data):
    return model(data)

    对比：

    模式 内存占用 速度 适用场景
    正常模式 高（保存中间激活用于反向传播） 慢 训练阶段
    torch.no_grad() 低（不保存中间激活） 快 2-3× 推理/评估
    torch.inference_mode() 最低（更激进的优化） 最快 纯推理（PyTorch 1.9+）

    3.3.4 自定义神经网络¶

    构建自定义模块需要实现两个方法：__init__（定义子模块）和 forward（定义前向传播）：

    class MLP(nn.Module):
    """3 层 MLP（Multi-Layer Perceptron），用于 MNIST 分类"""

    def __init__(self, input_dim=784, hidden_dims=[256, 128], num_classes=10, dropout=0.1):
        super().__init__()
        # 定义网络层
        self.fc1 = nn.Linear(input_dim, hidden_dims[0])
        self.fc2 = nn.Linear(hidden_dims[0], hidden_dims[1])
        self.fc3 = nn.Linear(hidden_dims[1], num_classes)
        self.dropout = nn.Dropout(dropout)
        self.act = nn.ReLU()

    def forward(self, x):
        """前向传播：x shape=(N, 784)"""
        x = x.view(x.size(0), -1)          # 展平输入
        x = self.act(self.fc1(x))          # Linear + ReLU
        x = self.dropout(x)                # Dropout 正则化
        x = self.act(self.fc2(x))          # Linear + ReLU
        x = self.dropout(x)
        x = self.fc3(x)                    # 输出层（无激活，留给 CrossEntropyLoss）
        return x

# 实例化模型
model = MLP()
print(model)

# 查看模型参数
params = list(model.parameters())
print(f"参数总数: {sum(p.numel() for p in params):,}")  # 约 218,698

# 保存和恢复模型状态字典
state_dict = model.state_dict()   # Dict[str, Tensor]，所有可训练参数
model.load_state_dict(state_dict) # 加载参数

    3.3.5 前向传播流程¶

    forward() 调用流程：

输入 x (N, 1, 28, 28)  ← MNIST 图像
  │
  ├── x = x.view(N, 784)          # 展平
  ├── x = fc1(x)                  # Linear(784→256) → (N, 256)
  ├── x = ReLU(x)                 # 激活
  ├── x = dropout(x)              # 正则化
  ├── x = fc2(x)                  # Linear(256→128) → (N, 128)
  ├── x = ReLU(x)
  ├── x = dropout(x)
  └── x = fc3(x)                  # Linear(128→10) → (N, 10)

输出 logits (N, 10)      ← 10 个类别的原始分数
  ↓
CrossEntropyLoss(logits, labels)  ← 内部做 Softmax + NLLLoss

    3.4 损失函数（Loss Functions）¶

    PyTorch 在 torch.nn 中提供了丰富的损失函数，其中 nn.Module 的子类可像普通层一样使用。

    import torch.nn as nn

# ===================== 分类任务 =====================

# 交叉熵损失（分类标准选择）
# 内部组合了 LogSoftmax + NLLLoss，输入是原始 logits（无需手动 softmax）
ce_loss = nn.CrossEntropyLoss()

logits = torch.randn(16, 10)    # (batch=16, num_classes=10)
labels = torch.randint(0, 10, (16,))  # 类别索引 [0,9]
loss = ce_loss(logits, labels)  # 标量损失值

# ===================== 二分类任务 =====================

# BCEWithLogitsLoss（二分类标准选择）
# 内部组合了 Sigmoid + BCELoss，输入是原始 logits
bce_loss = nn.BCEWithLogitsLoss()

logits_bin = torch.randn(16, 1)   # (batch, 1)
labels_bin = torch.randint(0, 2, (16, 1)).float()
loss_bin = bce_loss(logits_bin, labels_bin)

# ===================== 回归任务 =====================

# 均方误差损失（回归标准选择）
mse_loss = nn.MSELoss()

predictions = torch.randn(16, 1)   # 预测值
targets = torch.randn(16, 1)       # 真实值
loss_mse = mse_loss(predictions, targets)

# ===================== 对比/排序任务 =====================

# KL 散度（蒸馏、分布匹配）
kl_loss = nn.KLDivLoss(reduction="batchmean")
# 注意：input 需要是 log-probabilities（用 F.log_softmax 处理）

# Triplet Margin Loss（度量学习）
triplet_loss = nn.TripletMarginLoss(margin=1.0)

    各损失函数使用场景速查：

    损失函数 输入要求 输出范围 典型数值 场景
    CrossEntropyLoss logits, 类别索引 [0, +∞) ~0.1-5.0 多分类
    BCEWithLogitsLoss logits, 二值标签 (0/1) [0, +∞) ~0.01-1.0 二分类、多标签
    MSELoss 任意浮点值 [0, +∞) 取决于数据范围 回归
    L1Loss 任意浮点值 [0, +∞) 取决于数据范围 回归（鲁棒）
    KLDivLoss log-prob, 概率 [0, +∞) ~0.001-0.1 蒸馏、分布匹配

class ImageDataset(Dataset):
    """自定义图像数据集：从文件夹加载图像和标签"""

    def __init__(self, image_dir, labels_file, transform=None):
        """
        Args:
            image_dir: 图像文件夹路径
            labels_file: 标签文件（每行: 文件名,类别ID）
            transform: 图像预处理/增强管线

        self.transform = transform or T.ToTensor()

        self.samples = []
        with open(labels_file, "r") as f:
            for line in f:
                filename, label = line.strip().split(",")
                self.samples.append((filename, int(label)))

    def __len__(self):
        """返回数据集大小"""
        return len(self.samples)

    def __getitem__(self, idx):
        """根据索引返回 (image, label) 对"""
        filename, label = self.samples[idx]
        image_path = os.path.join(self.image_dir, filename)

        # 加载图像并应用变换
        image = Image.open(image_path).convert("RGB")
        if self.transform:
            image = self.transform(image)

        return image, label

import warnings

valid_loader = DataLoader(valid_dataset, batch_size=64, shuffle=False, num_workers=2)

# ==================== 3. 定义模型 ====================
class Classifier(nn.Module):
    """4 层分类器网络"""

    def __init__(self, input_dim=20, hidden_dim=64, num_classes=2, dropout=0.2):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim // 2, num_classes),
        )

    def forward(self, x):
        return self.net(x)

model = Classifier().to(device)
print(f"模型参数量: {sum(p.numel() for p in model.parameters()):,}")

# ==================== 4. 配置损失与优化器 ====================
criterion = nn.CrossEntropyLoss()
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50, eta_min=1e-6)

# ==================== 5. 训练循环 ====================

def train_epoch(model, loader, criterion, optimizer, device):
    """训练一个 Epoch，返回平均损失和准确率"""
    model.train()                             # 训练模式（启用 Dropout/BatchNorm）
    total_loss = 0.0
    correct = 0
    total = 0

    for X_batch, y_batch in loader:
        X_batch, y_batch = X_batch.to(device), y_batch.to(device)

        optimizer.zero_grad()                 # 清零梯度
        outputs = model(X_batch)              # 前向传播
        loss = criterion(outputs, y_batch)    # 计算损失
        loss.backward()                       # 反向传播
        optimizer.step()                      # 参数更新

        total_loss += loss.item() * X_batch.size(0)
        _, predicted = outputs.max(1)
        correct += predicted.eq(y_batch).sum().item()
        total += y_batch.size(0)

    avg_loss = total_loss / total
    accuracy = correct / total
    return avg_loss, accuracy


@torch.no_grad()                             # 推理模式：不计算梯度
def evaluate(model, loader, criterion, device):
    """在验证集上评估模型"""
    model.eval()                              # 评估模式（关闭 Dropout）
    total_loss = 0.0
    correct = 0
    total = 0

    for X_batch, y_batch in loader:
        X_batch, y_batch = X_batch.to(device), y_batch.to(device)
        outputs = model(X_batch)
        loss = criterion(outputs, y_batch)

        total_loss += loss.item() * X_batch.size(0)
        _, predicted = outputs.max(1)
        correct += predicted.eq(y_batch).sum().item()
        total += y_batch.size(0)

    avg_loss = total_loss / total
    accuracy = correct / total
    return avg_loss, accuracy

# ==================== 6. 训练主循环（含早停） ====================

best_model_state = None

      f"{'Valid Loss':<12} {'Valid Acc':<12} {'LR':<12}")

    train_loss, train_acc = train_epoch(model, train_loader, criterion, optimizer, device)
    valid_loss, valid_acc = evaluate(model, valid_loader, criterion, device)

          f"{valid_loss:<12.4f} {valid_acc:<12.4f} {current_lr:<12.2e}")

    # 学习率调度
    scheduler.step()

    # 早停检查——用验证损失判断
    if valid_loss < best_valid_loss:
        best_valid_loss = valid_loss
        best_model_state = model.state_dict()  # 保存最优模型
        patience_counter = 0                   # 重置计数器

        if patience_counter >= patience:
            print(f"\n早停触发！验证损失 {patience} 个 Epoch 未下降。")
            break

# ==================== 7. 加载最优模型并输出最终结果 ====================

    5.4 保存/加载方式对比¶

    方式 保存内容 文件大小（7B模型） 是否可恢复训练 跨版本兼容 适用场景
    state_dict 模型权重 ~14 GB (BF16) 仅推理 好 推理部署、HuggingFace 发布
    完整检查点 权重 + 优化器 + 调度器 + epoch ~30-50 GB 完整恢复 需同版本 训练中断恢复
    torch.jit.trace 计算图 + 权重 ~14 GB 跨语言 (C++) 生产推理
    ONNX 计算图 + 权重 ~14 GB 跨框架 多平台部署

    关键原则：HuggingFace 等模型仓库禁止上传包含优化器状态的完整检查点——不仅文件过大，而且可能涉及隐私信息（如优化器状态中的梯度历史）。发布模型时只上传 state_dict 或 safetensors 格式的权重文件。

    6.3 多 GPU 训练：nn.DataParallel vs nn.DistributedDataParallel¶

    # ==================== DataParallel（简单但不推荐） ====================
# 原理：将 batch 切分到各 GPU，主卡收集结果
# 缺点：主卡负载高，不支持多节点，速度慢于 DDP

if torch.cuda.device_count() > 1:
    model = nn.DataParallel(model)   # 自动使用所有可见 GPU
model.to(device)

# ==================== DistributedDataParallel（推荐） ====================
# 原理：各卡独立 forward/backward，梯度同步使用 All-Reduce
# 优点：负载均衡，支持多节点，速度快

# 启动方式：torchrun --nproc_per_node=4 train_ddp.py
import torch.distributed as dist
import torch.multiprocessing as mp
from torch.nn.parallel import DistributedDataParallel as DDP

def setup(rank, world_size):
    """初始化分布式环境"""
    dist.init_process_group(
        backend="nccl",                # NCCL 是 GPU 通信的最佳后端
        init_method="env://",
        world_size=world_size,
        rank=rank,
    )
    torch.cuda.set_device(rank)

def cleanup():
    dist.destroy_process_group()

def train_ddp(rank, world_size):
    setup(rank, world_size)

    # 每个进程创建模型并移到对应 GPU
    model = MLP().to(rank)
    model = DDP(model, device_ids=[rank])

    # 每个进程读取数据的不同部分（需使用 DistributedSampler）
    sampler = torch.utils.data.distributed.DistributedSampler(
        train_dataset, num_replicas=world_size, rank=rank
    )
    train_loader = DataLoader(train_dataset, batch_size=64, sampler=sampler)

    for epoch in range(10):
        sampler.set_epoch(epoch)         # 确保每 epoch 不同打乱
        for X_batch, y_batch in train_loader:
            X_batch, y_batch = X_batch.to(rank), y_batch.to(rank)
            optimizer.zero_grad()
            outputs = model(X_batch)
            loss = criterion(outputs, y_batch)
            loss.backward()
            optimizer.step()

    cleanup()

if __name__ == "__main__":
    world_size = torch.cuda.device_count()
    mp.spawn(train_ddp, args=(world_size,), nprocs=world_size)

    6.4 混合精度训练（AMP）¶

    混合精度训练（Automatic Mixed Precision）使用 FP16/BF16 加速计算，同时保持 FP32 精度关键部分（损失计算、梯度更新）：

    from torch.cuda.amp import autocast, GradScaler

# GradScaler：防止 FP16 梯度下溢
scaler = GradScaler()

model = MLP().to(device)
optimizer = optim.AdamW(model.parameters(), lr=1e-3)

for epoch in range(10):
    for X_batch, y_batch in train_loader:
        X_batch, y_batch = X_batch.to(device), y_batch.to(device)

        optimizer.zero_grad()

        # autocast 上下文：自动选择 FP16/BF16 或 FP32
        with autocast(device_type="cuda", dtype=torch.float16):
            outputs = model(X_batch)
            loss = criterion(outputs, y_batch)

        # 梯度缩放 + 反向传播
        scaler.scale(loss).backward()

        # 更新参数（自动反缩放）
        scaler.step(optimizer)
        scaler.update()

# ==================== BF16 混合精度（A100+ 推荐） ====================
# BF16 无需 Loss Scaling，动态范围与 FP32 相同，更稳定

with autocast(device_type="cuda", dtype=torch.bfloat16):
    outputs = model(X_batch)
    loss = criterion(outputs, y_batch)
loss.backward()
optimizer.step()  # BF16 无需 GradScaler

    精度格式对比：

    格式 显存节省 速度提升 精度损失 硬件要求 Loss Scaling
    FP32（基线） 1× 1× 无 所有 GPU
    FP16 AMP ~2× ~2-3× 少量 V100+ 需要
    BF16 AMP ~2× ~2-3× 极少量 A100+ 不需要

    八、JAX 核心概念（简要）¶

    8.1 JAX 的设计哲学¶

    JAX 不是传统意义上的深度学习框架——它更接近一个可微分编程编译器。核心原则：

    1. 函数式（Functional）：所有计算是纯函数，无状态、无副作用
    2. NumPy 兼容：jax.numpy 是 NumPy API 到 GPU/TPU 的直接映射
    3. 变换式（Transformations）：通过函数变换组合计算能力

    8.2 核心变换¶

    import jax
import jax.numpy as jnp
from jax import grad, jit, vmap, pmap

# ==================== jit：即时编译加速 ====================
@jit
def f(x):
    for _ in range(1000):
        x = x * 1.001 + 0.001
    return x

# 第一次调用时编译（较慢），后续调用走编译后的 XLA 代码
result = f(jnp.array(1.0))

# ==================== grad：自动微分 ====================
def loss_fn(w, x, y):
    """线性回归损失"""
    pred = w[0] * x + w[1]
    return jnp.mean((pred - y) ** 2)

# grad(f, argnums=...) 指定对哪个参数求导
grad_loss = grad(loss_fn, argnums=0)  # 对 w 求导

# 数值验证：f(x) = x² + 2x + 1, df/dx = 2x + 2
f_simple = lambda x: x**2 + 2*x + 1
print(grad(f_simple)(2.0))  # 6.0 ✓

# ==================== vmap：自动向量化 ====================
# 处理批量数据，无需手动写 batch 维度
def single_sample(x, w):
    return jnp.dot(w, x)

# 对 batch 维度自动向量化
batched_predict = vmap(single_sample, in_axes=(0, None))
# in_axes=(0, None) 表示第一个参数按第0维 batch，第二个参数广播

# ==================== pmap：多设备并行 ====================
# 在多个 GPU/TPU 上执行 SPMD（单程序多数据）
n_devices = jax.device_count()
parallel_fn = pmap(lambda x: x ** 2)
# 输入切分到各设备并行计算

    8.3 完整示例：JAX 线性回归¶

    import jax
import jax.numpy as jnp
from jax import grad, jit
import optax  # JAX 生态的优化器库

# 生成合成数据
key = jax.random.PRNGKey(42)
X = jax.random.normal(key, (100, 1))
true_w = jnp.array([[2.0], [-1.0]])  # 真实权重
y = X @ true_w + 0.1 * jax.random.normal(key, (100, 1))

# 定义模型和损失
def predict(w, x):
    return x @ w[:-1] + w[-1]  # 线性回归: y = wx + b

def mse_loss(w, x, y):
    pred = predict(w, x)
    return jnp.mean((pred - y) ** 2)

# 初始化参数
w = jnp.array([[0.0], [0.0], [0.0]])  # [w1, w2, bias]

# 使用 optax 优化器
optimizer = optax.adam(learning_rate=1e-1)
opt_state = optimizer.init(w)

@jit
def step(w, opt_state, x, y):
    loss_val, grads = jax.value_and_grad(mse_loss)(w, x, y)
    updates, opt_state = optimizer.update(grads, opt_state, w)
    w = optax.apply_updates(w, updates)
    return w, opt_state, loss_val

# 训练循环
for epoch in range(100):
    w, opt_state, loss = step(w, opt_state, X, y)
    if epoch % 20 == 0:
        print(f"Epoch {epoch}: Loss = {loss:.4f}")

print(f"真实权重: {true_w.flatten()}")
print(f"学习到的权重: {w[:-1].flatten()}, bias: {w[-1]:.4f}")

    10.3 常见错误与解决方案¶

    RuntimeError: CUDA out of memory¶

    错误信息：
RuntimeError: CUDA out of memory. Tried to allocate 512.00 MiB.
GPU 0 has a total capacity of 23.69 GiB. Of which 22.50 GiB is allocated by PyTorch.

可能原因与解法：
┌─────────────────────────────────────────────────────────────────┐
│  1. Batch Size 过大                                            │
│     → 减小 batch_size（如 64→32→16）                           │
│                                                                │
│  2. 序列过长（LLM 场景）                                        │
│     → 减小 max_seq_length                                      │
│     → 使用梯度检查点（Gradient Checkpointing）                  │
│                                                                │
│  3. 前一步的显存未释放                                          │
│     → 确认每次循环后不再保留计算图（detach/no_grad）            │
│     → torch.cuda.empty_cache() 清理缓存（缓解用，非根本解决）   │
│                                                                │
│  4. 多进程数据加载的 pin_memory 占用                            │
│     → 减小 num_workers                                          │
└─────────────────────────────────────────────────────────────────┘

排查命令：
  nvidia-smi                    # 查看 GPU 显存占用
  torch.cuda.memory_summary()   # PyTorch 内存分配详情

    inplace 操作错误¶

    错误信息：
RuntimeError: one of the variables needed for gradient computation has been
modified by an inplace operation

原因：inplace 操作（如 x += 1、x.view_()）修改了计算图中需要保留的张量。

常见场景与修复：
  ❌ x += 1                     # inplace 加法
  ✅ x = x + 1                  # 新分配张量

  ❌ x.view_(-1, 784)            # inplace reshape
  ✅ x = x.view(-1, 784)        # 新分配张量

  ❌ relu(x, inplace=True)      # inplace ReLU
  ✅ x = relu(x)                # 不原地修改
